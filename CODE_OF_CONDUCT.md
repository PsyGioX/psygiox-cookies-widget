# Code of conduct

Be respectful. Discuss code and ideas, not people. No harassment, discrimination, personal attacks or publishing other people’s private information. Keep issues on topic and assume good faith.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules and may block repeat offenders. Report problems through a private security advisory or by contacting the maintainer [PsyGioX](https://github.com/PsyGioX) on GitHub.
