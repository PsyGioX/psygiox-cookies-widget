Чего не умеют обычные баннеры куки-файлов

Баннер, который только спрашивает, — это полдела. PGX ещё и следит, что страница реально записывает, и действует.

◉

Cookie Radar — трекинг в реальном времени

Виджет оборачивает запись document.cookie и слушает Cookie Store API: каждый новый, изменённый и удалённый куки-файл мгновенно попадает в журнал — с категорией, вендором и размером. Живую панель можно встроить в свою админку.

PsyCookies.on('cookie', e => console.log(e.type, e.name, e.category));
PsyCookies.live.mount('#cookie-monitor');
⛨

Cookie Guard

Нет согласия — нет куки-файла. Запись аналитики и рекламы блокируется на лету, а появившиеся «снаружи» куки-файлы удаляются.

Регион определяется по часовому поясу браузера — это эвристика. Для точности передавайте его с сервера (data-region, например из заголовка x-vercel-ip-country). Виджет — инструмент, а не юридическая консультация: тексты и сроки для вашего случая должен проверить юрист.

i18n

Переводы без тяжёлого парсера

Никакого ICU-парсера: множественные числа, числа, даты и списки считает браузер. Пакет — одна строка, а свой язык добавляется одним вызовом.

// a pack is just data; the order of loading does not matter
PsyCookies.i18n.add('de', {
  'banner.title': 'Ihre Privatsphäre ist uns wichtig',
  'banner.reject@us': 'Reject non-essential', // region variant
  'live.total': {                           // Intl.PluralRules
    one:   '{n} Cookie auf dieser Seite',
    other: '{n} Cookies auf dieser Seite'
  }
});
PsyCookies.i18n.set('de');   // or data-lang="auto"
PsyCookies.i18n.t('live.total', { n: 5 });

Ссылкой или архивом

Выберите, как удобнее. К любому способу прилагаются хеши для проверки.

  1. Вставьте тег первым скриптом в <head>. Папка с версией никогда не меняется, поэтому хеш SRI остаётся верным.
  2. Добавьте ссылки на свои документы и (по желанию) регион с сервера. CSS и языковые пакеты подтянутся сами.
  3. Повесьте data-pc-open на любую ссылку, чтобы открывать настройки повторно.
<script src="https://psygiox-cookies-widget.vercel.app/widget/dist/v1.0.0/psygiox-cookies.min.js"
        integrity="sha384-9u0iIMFa4Qx/++FAD8AAd3Q9QgAsVDgdEFxDQplaPZ9ZEjiG0DALgfCgTKwVTuCS" crossorigin="anonymous"
        data-policy="/cookies" data-privacy="/privacy"></script>

api

Настройка атрибутами, кодом или JSON

Одни и те же опции везде. Более поздние источники важнее: значения по умолчанию → PsyCookiesConfig → data-атрибуты → init()/configure() → удалённый JSON.

<!-- 1. attributes -->
<script src=".../psygiox-cookies.min.js"
  data-region="eu" data-lang="auto" data-theme="dark"
  data-position="bottom-right" data-guard="enforce"
  data-tokens='{"accent":"#7dff2e","radius":"20px"}'
  data-receipt="/api/consent"></script>

// 2. code
PsyCookies.configure({
  categories: [{ id: 'chat', labels: { en: { title: 'Chat' } } }],
  cookieRules: [{ match: '^chat_', category: 'chat' }]
});
// 3. runtime
PsyCookies.open('live');              // banner | settings | live
PsyCookies.set({ analytics: true });
PsyCookies.allowed('marketing');       // boolean
PsyCookies.theme.set('dark');
PsyCookies.cookies.list();           // name, category, status…

// 4. events
PsyCookies.on('consent', e => console.log(e.granted, e.revoked));
PsyCookies.on('violation', e => report(e.name));
addEventListener('psygiox-cookies:change', console.log);

faq

Вопросы и ответы

Это юридическая консультация?
Нет. Виджет реализует общепринятые практики для каждого региона с консервативными настройками по умолчанию, но ваши тексты, сроки и список куки-файлов зависят от сайта. Покажите их юристу.
Как выбирается регион?
По часовому поясу браузера: российские пояса → ru, Европа → eu, пояса США → us, всё остальное → world (строгая модель opt-in). Это эвристика, поэтому при необходимости передавайте настоящий регион с сервера в data-region.
Можно ли на коммерческом сайте?
Да, GPL-3.0 это разрешает. Если вы изменяете виджет и распространяете результат, публикуйте изменения под той же лицензией. Читаемые исходники отдаются из /widget/src/. Это краткое пояснение, а не юридическая консультация.
Что именно видит Cookie Guard?
Куки-файлы, доступные скриптам страницы: записанные через document.cookie и появившиеся в хранилище (их находят события Cookie Store и лёгкая проверка). HttpOnly-куки-файлы не видны ни одному скрипту — ими управляют на сервере. Значения никогда не показываются и не сохраняются.
Работает ли с Google Tag Manager?
Да. Сигналы Consent Mode v2 отправляются до загрузки GTM (держите виджет первым), а событие dataLayer psygiox_consent доступно как триггер.
Что хранит этот сайт?
Только необходимый куки-файл psygiox_consent (ваш выбор, до 6–12 месяцев) и офлайн-кэш PWA. Ни аналитики, ни рекламы, ни внешних запросов. Куки-файлы, созданные в демо, пишете вы сами, и они живут только в вашем браузере.
